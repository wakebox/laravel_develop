5.  []{#六、作業方式 .anchor}作業方式：

> 欄位說明

+--------------+--------------------------------------------------+
| 欄位名稱     | 欄位說明                                         |
+==============+==================================================+
| 財產編號     | **必填欄位**                                     |
|              |                                                  |
|              | **下拉式選單**                                   |
|              |                                                  |
|              | 需過濾以下條件：                                 |
|              |                                                  |
|              | 1.  不能為非列帳資產(即資產列管/列帳=2)          |
|              |                                                  |
|              | 2.  該資產之庫存數量=0                           |
+--------------+--------------------------------------------------+
| 資產名稱     | **唯讀欄位**                                     |
|              |                                                  |
|              | 根據選擇之財產編號帶出其資產名稱                 |
+--------------+--------------------------------------------------+
| 資產規格     | **唯讀欄位**                                     |
|              |                                                  |
|              | 根據選擇之財產編號帶出其資產規格                 |
+--------------+--------------------------------------------------+
| 重估日期     | **必填欄位**                                     |
|              |                                                  |
|              | **萬年曆選單**                                   |
+--------------+--------------------------------------------------+
| 重估單號     | 無法編輯                                         |
|              |                                                  |
|              | 系統自動賦予                                     |
|              |                                                  |
|              | **編碼原則：請依OA3.0單據架構設計(RD補充)**      |
+--------------+--------------------------------------------------+
| 重估原因     | **必填欄位**                                     |
|              |                                                  |
|              | 使用者自行輸入改良原因                           |
+--------------+--------------------------------------------------+

重估區欄位說明

+--------------+--------------------------------------------------+
| 欄位名稱     | 欄位說明                                         |
+==============+==================================================+
| 重估差價     | **必填欄位**                                     |
|              |                                                  |
|              | 只允許輸入正or負整數                             |
+--------------+--------------------------------------------------+
| 增減預留殘值 | 只允許輸入正or負整數                             |
+--------------+--------------------------------------------------+

存檔處理：

資產基本檔

  ------------------------------------------------------------------
  欄位名稱        欄位說明
  --------------- --------------------------------------------------
  成本總額        需加上重估差價之金額(可以為減項)

  預留殘值        需加上增減預留殘值

  重估差價        需加上重估單之重估差價
  ------------------------------------------------------------------

> 異動記錄欄位說明

  ------------------------------------------------------------------
  欄位名稱        欄位說明
  --------------- --------------------------------------------------
  序號            系統自動流水編號賦予

  異動類型        重估

  保管人          舊保管人

  異動數量        依資產數量

  異動金額        資產重估單Link

  異動時間        依系統時間寫入
  ------------------------------------------------------------------
