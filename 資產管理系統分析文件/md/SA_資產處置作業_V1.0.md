> 欄位說明

+--------------+--------------------------------------------------+
| 欄位名稱     | 欄位說明                                         |
+==============+==================================================+
| 財產編號     | **必填欄位**                                     |
|              |                                                  |
|              | **下拉式選單**                                   |
|              |                                                  |
|              | 需過濾以下條件：                                 |
|              |                                                  |
|              | 1.  不能為非列帳資產(即資產列管/列帳=2)          |
|              |                                                  |
|              | 2.  該資產之抵押狀態不能為2.已抵押               |
|              |                                                  |
|              | 3.  該資產之庫存數量=0                           |
+--------------+--------------------------------------------------+
| 資產名稱     | **唯讀欄位**                                     |
|              |                                                  |
|              | 根據選擇之財產編號帶出其資產名稱                 |
+--------------+--------------------------------------------------+
| 資產規格     | **唯讀欄位**                                     |
|              |                                                  |
|              | 根據選擇之財產編號帶出其資產規格                 |
+--------------+--------------------------------------------------+
| 處置類型     | **必填欄位**                                     |
|              |                                                  |
|              | **下拉式選單**                                   |
|              |                                                  |
|              | S.出售                                           |
|              |                                                  |
|              | D.報廢                                           |
+--------------+--------------------------------------------------+
| 處置單號     | 無法編輯                                         |
|              |                                                  |
|              | 系統自動賦予                                     |
|              |                                                  |
|              | **編碼原則：請依OA3.0單據架構設計(RD補充)**      |
+--------------+--------------------------------------------------+
| 處置日期     | **必填欄位**                                     |
|              |                                                  |
|              | **下拉萬年曆選單**                               |
+--------------+--------------------------------------------------+

> 基本區欄位說明

+--------------+---------------------------------------------------------+
| 欄位名稱     | 欄位說明                                                |
+==============+=========================================================+
| 剩餘年限(月) | **唯讀欄位**                                            |
|              |                                                         |
|              | 以耐用年限扣除(系統年月扣除取得日期年月)推算            |
|              |                                                         |
|              | 若得值為負數，則一律顯示為0。                           |
|              |                                                         |
|              | EX1：耐用年限=30個月;系統年月=2025/11;取得年月=2025/05; |
|              |                                                         |
|              | 30-(11-6)=25                                            |
|              |                                                         |
|              | 故剩餘年限=25個月                                       |
|              |                                                         |
|              | EX2：耐用年限=30個月;系統年月2025/11;取得年月=2023/03;  |
|              |                                                         |
|              | 30-32=-2，得值為負數，代表已經無剩餘年限，故剩餘年限=0  |
+--------------+---------------------------------------------------------+
| 處置前數量   | **唯讀欄位**                                            |
|              |                                                         |
|              | 依單頭選擇之處置資產，關聯資產基本檔取得取得數量。      |
+--------------+---------------------------------------------------------+
| 成本總額     | **唯讀欄位**                                            |
|              |                                                         |
|              | 依單頭選擇之處置資產，關聯資產基本檔取得取得成本總額。  |
+--------------+---------------------------------------------------------+
| 預留殘值     | **唯讀欄位**                                            |
|              |                                                         |
|              | 依單頭選擇之處置資產，關聯資產基本檔取得取得預留殘值。  |
+--------------+---------------------------------------------------------+
| 本期折舊     | **唯讀欄位**                                            |
|              |                                                         |
|              | 依單頭選擇之處置資產，關聯資產每月資產每月攤提折舊。    |
|              |                                                         |
|              | 依單頭處置日期，去得每月攤提折舊之當月攤提金額。        |
+--------------+---------------------------------------------------------+
| 期末累折     | **唯讀欄位**                                            |
|              |                                                         |
|              | 依單頭選擇之處置資產，關聯資產每月資產每月攤提折舊。    |
|              |                                                         |
|              | 依單頭處置日期，去得每月攤提折舊之累積折舊金額。        |
+--------------+---------------------------------------------------------+
| 期末殘值     | **唯讀欄位**                                            |
|              |                                                         |
|              | 成本總額-期末殘值                                       |
+--------------+---------------------------------------------------------+

> 異動記錄欄位說明

+--------------+--------------------------------------------------+
| 欄位名稱     | 欄位說明                                         |
+==============+==================================================+
| 序號         | 系統自動流水編號賦予                             |
+--------------+--------------------------------------------------+
| 異動類型     | 後續透過其他資產異動作業回寫                     |
|              |                                                  |
|              | 暫定類型                                         |
|              |                                                  |
|              | IF 單頭處置類型=S.出售，則存入出售               |
|              |                                                  |
|              | IF 單頭處置類型=D.報廢，則存入報廢               |
+--------------+--------------------------------------------------+
| 保管人       | 依該資產保管人寫入(處置不影響保管人)             |
+--------------+--------------------------------------------------+
| 異動數量     | 寫入處置數量                                     |
+--------------+--------------------------------------------------+
| 異動金額     | 寫入處置售價                                     |
+--------------+--------------------------------------------------+
| 異動時間     | 依系統時間寫入                                   |
+--------------+--------------------------------------------------+
