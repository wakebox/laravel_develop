> 資產編碼原則

+--------------+--------------------------------------------------+
| 欄位名稱     | 欄位說明                                         |
+==============+==================================================+
| 流水號碼數   | **必填欄位**                                     |
|              |                                                  |
|              | 只允許輸入正整數1-9                              |
|              |                                                  |
|              | 流水號碼數會接在所有原則最後面並流水號註記       |
+--------------+--------------------------------------------------+
| 順序         | 系統自動賦予                                     |
|              |                                                  |
|              | 新增一筆即為1..2..3...依此類推                   |
+--------------+--------------------------------------------------+
| 類別代碼     | **下拉式選單**                                   |
|              |                                                  |
|              | 資料來源為編碼類別維護                           |
+--------------+--------------------------------------------------+
| 類別名稱     | **唯讀**                                         |
|              |                                                  |
|              | 根據類別代碼帶出其類別名稱                       |
